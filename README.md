# Teaboom — тестовое задание

Тестовое задание: верхняя часть карточки товара «Ананасовый улун» для интернет-магазина чая [Teaboom.ru](https://teaboom.ru).

## 🔗 Демо

Живая версия на GitHub Pages: **https://inu255.github.io/teaboom-test/**

## Стек

- HTML5 (семантическая разметка)
- SCSS / Sass — компилируется в `css/style.css`
- Без JS-фреймворков

## Требования

- [Node.js](https://nodejs.org/) и npm (проект собран и проверен на Node v22 / npm 11)

## Установка

```bash
npm install
```

## Запуск

Режим разработки — автокомпиляция SCSS при каждом изменении файлов:

```bash
npm run dev
```

Разовая сборка CSS:

```bash
npm run build
```

После сборки достаточно открыть `index.html` в браузере (например, через расширение Live Server или любой локальный сервер).
